# Testing evidence

Voyager records proof by the surface that can settle the claim:

| Surface | What it proves |
|---|---|
| Unit/contract | Source-level invariants through Vitest |
| Disposable PostgreSQL | Migration, concurrency, and SQL behavior in a pinned no-network container |
| Development environment | Authorized hosted behavior; never production |
| Product/browser | The real preview journey through invited test accounts |

Historical receipts live under `receipts/memory/`. They are evidence of what
ran at their recorded revision, not current executable instructions. Current
commands live in the root README and `recipes/README.md`.

Each receipt retains its exact revision, status, claim and surface, actions,
counts and shapes, observed verdict, limitations, and residue. Exact hosted
refs, account handles, personal messages, source ids, session topology,
screenshots, raw provider output, and operational logs stay in owner-only
evidence.
