# Native avatar animation verification

This patch records the focused changes to the existing integrated proving fixture. It reuses its Native input, capture, Core, identity and cleanup helpers. It does not introduce another application runner. Apply with git apply --unidiff-zero only to source matching source-manifest.json; this archive depends on the preserved integrated foundation fixture, not a standalone checkout of this branch.

The changes verify hover, held commands, full and compact docking, custom JSON/PNG reload, invalid-reference and corrupt-PNG recovery, visible repaired-error clearing, click minimize/restore, observed terminal focus before keys and reduced motion. Each clip records its trigger clock, actual source frames and finite hold exceptions. A missing-hover release is the known-different comparison. Independent mouse movement stops the round.

The owner restoration change removes only fullscreen/maximize flags absent from the recorded initial state, retaining exact identity, geometry, layout, program and active-window checks. It passed six independent exact-source controls.

The final native run completes both enabled and reduced-motion cases with original sessions preserved. Earlier setup, status-accessibility, unobserved-focus and pointer refusals remain separate. Raw profiles, screenshots, frame data and private review records stay outside Git. The combined proving-code inventory, typing parity and full foundation acceptance remain open.

The archive was applied in an isolated directory and all four resulting files matched their recorded hashes. Product behavior is supplied by the preceding typed-format, loader and native-player PRs. This archive does not establish long-term memory retention, physical display latency or another platform.
