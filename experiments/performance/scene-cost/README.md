# Static terminal scene diagnostic

This records the retained-viewer fixture used to investigate the UI CPU gap
between Voyager and Herdr. It changes no selected application behavior.

The coordinator compares sparse and dense static terminal screens on ordinary
release binaries, with normal Voyager animation and two diagnostic animation-off
controls. It checks exact process, Core, window and text identities, observes
resources, records screenshots after measurement and restores the owner preview.
Animation-off controls do not define an acceptable product configuration.

The patch extends the fixture retained by the preceding paired-viewer record.
It requires that record and the same unfinished foundation source and maintained
native helpers. Apply it with `git apply --unidiff-zero`. This archive alone is
not a runnable application or a performance acceptance suite.

The strict AMD counter validator is shared with the earlier owner check. The
first measured collector had a weaker string comparison. Its source is preserved
with the private protocol; the repaired analyzer and independent review validate
the retained counters before interpretation. No favorable rerun replaces it.

Profiles, raw observations, screenshots, machine-specific protocols and task
documents stay outside Git. The normalized foundation proof-size inventory,
latency, exact UX and platform acceptance gates remain open.
