# Pixel-identical idle redraw experiment

This unselected candidate preserves the avatar clock, poses, fades and interactions. During settled idle, it skips invalidation only while the measured image bounds remain identical after native pixel rounding. One pending callback still checks the original display cadence. Due poses, active transitions, dragging, missing measurements and changed geometry invalidate normally. The patch records the implementation and its focused checks; this folder does not apply it to the product.

Four loaded Codex runs used one release with the control off, on, on, then off. All 48 characters, load completion, process identities and exact owner restoration passed independent review. UI-thread CPU fell from 12.7–18.8% of one core to 3.4–3.6%. Captured median bounds were 45–87 ms enabled and 55–85 ms disabled. The p95 upper bounds were 141 ms and 135 ms. Wide capture intervals remain in those figures. This establishes a resource improvement in these observations, not a typing-latency repair or Herdr parity. Native animation phase and pixel fidelity remain unproved, so the candidate is not selected for the review preview.

The geometry check includes the layout engine's rounding of authored absolute positions before painting. Raw translation by the float delta is incorrect near fractional thresholds. Actual-library controls verify pose deadlines and the snapped-edge arithmetic; deliberately removing the deadline or using raw translation fails. These checks do not establish native animation equivalence.

Private protocols, release artifacts, recordings and reviews remain outside Git under the pixel-motion records in /var/tmp/voyager-typing-latency-20261108/. The patch targets its recorded performance-experiment baseline, not an arbitrary checkout. The next diagnostic follows the exact typed character from parsed terminal state through drawing and submission. Full UX, resource, proof-size and foundation acceptance remain open.
