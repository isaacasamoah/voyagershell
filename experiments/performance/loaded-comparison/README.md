# Loaded typing comparison

This archive records the focused fixture changes for the 9 November comparison. It extends the preserved startup-order and static-scene fixtures. It does not select a terminal renderer or accept the native foundation.

The comparison uses immutable release executables and disposable Core/Codex sessions. It types twelve characters without submitting a model prompt. Single-app quiet/CPU runs precede CPU runs with both apps visible. Launch and measurement order are balanced. Raw frame custody, exact final text, process identity, geometry and original-session retention remain required.

The patch allows CPU contention in a paired block, starts a fresh finite load for each peer measurement and preserves the existing warmup. It records the actual foreground process so the paired guard can validate Codex as well as the historical echo workload. GUI and command launches use the frozen Herdr executable. Optional experiment environment changes allow only PATH and VOYAGER_HC; the isolated Herdr profile also selects its frozen Core.

A still-running executable can become unlinked when an installed application updates. The shared identity helper validates the live procfs executable handle before normalizing the literal deleted suffix. UID and process start remain checked. This metadata name is not an executable-content hash. The experiment separately preserves the original Core inode and the release artifact hashes. A stale or missing handle still fails.

Window cleanup moves before restoring maximized/fullscreen state, waits for each saved flag and verifies exact geometry. It never resizes a maximized owner while that restoration is settling. Original Core, shell and Codex identities must survive. No user process is stopped to prepare or clean up a scratch run. A focus refusal records the actual window and its process/class properties before stopping input. The existing resource sampler can finish after an early refusal.

The first setup stopped before input on an incomplete owner record. The next completed two quiet observations, then Herdr installed a staged update and restarted before load scoring. Those partial attempts remain separate. A later focus interruption left four completed observations and one five-key failed attempt. The continuation keeps the completed observations with their original source identities and retries only the remaining cases. The restarted comparison freezes Herdr 0.1.14 and Core outside the installed update location.

The active fixture depends on the preserved integrated foundation source and prior experiment helpers. This patch is a reproducible delta against that recorded source, not a standalone benchmark checkout. Private protocols, source snapshots, profiles, screenshots and raw measurements stay outside Git. Results and remaining limits are recorded in the shared architecture walkthrough after the run.
