# Real-app rank hats experiment

This unmerged experiment adds explicit user-controlled rank metadata to the actual Rust workspace owner and existing native panel header. It does not create a messaging, assignment, supervision or permission system.

Hover a terminal panel. A small Captain hat sits after Split and before activity. Click to promote a Vessel from Crew to Captain, then Commodore. A Portal supports Crew to Admiral. Tooltips name the current role and next action. Right-click the panel title and choose Reset rank to Crew to reverse the trial. Notes and Activity do not receive rank controls.

Rank is a typed value on stable terminal content in the existing versioned workspace document. Core still owns programs. Promotion changes no backend, avatar context or caller policy. The owner refuses Admiral on a Vessel, Captain/Commodore on a Portal, skipped promotion and scoped agent-originated edits. Loading or moving an incompatible ranked placement refuses rather than granting a new scope.

The later communication design permits open conversation and one authority check at explicit work-changing operations. Admiral covers its Voyage, Commodore its Fleet, Captain its assigned Crew. Intermediate ranks are optional and guide routing where relevant. These remain later requirements and confer no powers here.

Implementation uses the existing `contract/`, `app/` and `desktop/` owners on this experiment branch, not a second app copy. The generated contract and maintained native `rank-hats` journey describe the actual path. Run the shared fixture with an isolated session/profile/XDG state and an identified optimized executable. It starts only two fresh Codex interfaces and submits no task prompt. Other provider activity is not measured. Never point it at a user's live workspace.

Results, exact source/artifact, private profile and failed attempts are recorded in the worktree-local task records and linked evidence. No merge, release, installation or current-preview replacement is authorized. Source/unit/native outcomes and the complete proof-size gate remain separate.
