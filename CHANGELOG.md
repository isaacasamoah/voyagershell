# Changelog

Each release lists what changed for the person using VoyagerShell. A release that changes the shape of data kept on disk says so, because going back to the previous build does not convert it.

## [0.1.0] - 2026-11-30

First release, for Linux x86_64.

- Install with one command, then start from the launcher or with `voyager start`.
- A new build downloads quietly while the app runs and offers Restart. Your programs keep running through the restart.
- `voyager rollback` goes back to the previous build.
- No stored data changes shape in this release.
